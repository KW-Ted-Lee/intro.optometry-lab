Week 04

視覺的形成：從視網膜到大腦

Visual Pathway, Blind Spot & Pinhole

光訊號離開眼球後，在視交叉「換邊」，最後在枕葉才真正被「看到」。本週還要實測自己的盲點，並用一張針孔卡判斷視力不好是屈光問題還是眼疾：針孔有進步 → 屈光；沒進步 → 該轉介了。

學習目標 GOALS

  • 說出從視網膜到枕葉視覺皮質的每一站，以及左右視野如何交叉。
  • 說出盲點的位置、大小，以及大腦用哪三種方式把它藏起來。
  • 說明針孔為什麼能改善視力，以及「有沒有改善」各代表什麼。

核心觀念 KEY IDEAS

Light path in the eye

光在眼球內走的路

角膜 → 前房 → 瞳孔 → 後房 → 水晶體 → 玻璃體 → 視網膜 → 視神經 → 大腦。會讓光轉彎的屈光間質有四個：角膜、房水、水晶體、玻璃體。

Visual pathway

完整視路

感光細胞 → 雙極細胞 → 神經節細胞 → 視神經 → 視交叉 → 視束 → 外側膝狀體 LGN（視丘） → 視放射 → 枕葉 V1。部分纖維在 LGN 前分出，負責瞳孔反射與眼球運動。

Optic chiasm

視交叉後左右換邊

鼻側視網膜纖維交叉到對側，顳側不交叉。結果：右腦處理兩眼的左半視野，左腦處理右半視野。注意「視網膜的左右」與「視野的左右」相反。

○ 知道即可Field defects

由視野缺損反推位置

單眼全盲 → 該側視神經；雙顳側偏盲 → 視交叉（腦下垂體腫瘤）；同側偏盲 → 對側視束或視放射；黃斑迴避的同側偏盲 → 枕葉皮質。本課只要求辨認前三種。

Blind spot

盲點

盲點是視盤在視野中的投影。位置在視野顳側約 15°、水平線略下方，大小約 5° × 7°。因為視盤在黃斑鼻側，而鼻側視網膜對應顳側視野。

Filling-in · Saccade

為什麼感覺不到盲點

一、大腦依周圍圖案自動填補；二、眼球跳視讓盲點位置一直在變；三、雙眼視野互相覆蓋，一眼的盲點另一眼看得到。盲點擴大是青光眼與視神經水腫的徵象。

Pinhole

針孔為什麼有用

小孔限制光束直徑 → 模糊圈變小、景深增加。最佳孔徑約 1.2 mm；太大限制不足，太小繞射變強、進光不足，視力反而下降。

Pinhole test

針孔檢查的判讀

戴針孔後進步 → 傾向未矯正的屈光問題，一般可到約 6/9。沒進步或變差 → 要懷疑介質混濁（白內障、角膜混濁）、黃斑部或視神經病變，這是轉介的訊號。

Ocular dominance

主利眼

大腦提供較多輸入、定位較準的那隻眼。測法：卡片洞法、拇指遮蔽法、Miles test（雙手三角孔）。約七成與慣用手同側但不絕對。用於老花單眼視配鏡（W14）、射擊與顯微鏡操作。

腦下垂體腫瘤由下往上壓迫視交叉，最可能出現哪種視野缺損？

視交叉處交叉的是兩眼「鼻側」視網膜的纖維，它們負責的是兩眼的「顳側」視野。

觀察重點

  • 下方兩個圓是病人自己看到的視野（左眼的在左、右眼的在右），黑色是看不到的部分，小黑點是盲點。
  • 橘色是會交叉的鼻側纖維，藍色是不交叉的顳側纖維。
  • 病灶在視交叉「之前」影響一隻眼；在視交叉「之後」影響兩眼的同一側。
LAB 4-2

盲點實測

你的盲點位置—
預期消失距離（15°）—

操作步驟

  • 遮住左眼，用右眼一直盯著左邊的十字，不要看圓點。
  • 臉從離螢幕約 50 cm 處慢慢靠近，圓點會在某個距離突然消失，再靠近又出現。
  • 量下消失時的距離，和十字到圓點的距離一起填入，算出你的盲點在顳側幾度。
  • 換成「斷掉的線」：圓點消失的位置，線看起來是連起來的——這就是大腦的填補。

目前孔徑的視力—

把孔徑一直縮小到 0.3 mm，視力會？

孔越小幾何模糊越小，但繞射模糊越大，最佳孔徑約 1.2 mm。

觀察重點

  • 近視病人：孔徑從 4 mm 縮到約 1.2 mm，視力明顯進步。
  • 切換到白內障或黃斑部病變：針孔幫不上忙，這就是轉介的訊號。
LAB 4-4

主利眼：卡片洞法

操作步驟

  • 雙手持有洞的卡片、手臂伸直，雙眼睜開，從洞裡看遠處的目標。
  • 輪流閉一隻眼：閉上某眼時目標「跑出洞外」，代表剛閉上的那隻才是主利眼。
  • 重複三次確認結果一致——這就是作業（三）。

常見迷思 MISCONCEPTIONS

左腦處理左眼、右腦處理右眼。
視交叉後是按「視野」分：左腦處理兩眼的右半視野，右腦處理兩眼的左半視野。
視盤在鼻側，所以盲點也在鼻側視野。
視網膜的位置與視野方向左右相反：鼻側視網膜 → 顳側視野。盲點在視野顳側約 15°。
盲點很小，大概只有一個針尖。
約 5° × 7°，比多數人想像的大很多。在一臂距離大約是一顆高爾夫球大小。
針孔越小越清楚。
太小會因繞射變糊、進光量也不足。最佳孔徑約 1.2 mm。
主利眼一定跟慣用手同一邊。
約七成同側，但兩者並非絕對相關。要實際測過才知道。
