核心觀念 KEY IDEAS

Conoid of Sturm

Sturm 光錐

散光眼的光線形成立體光錐：前焦線（較強子午線的像）、後焦線（較弱子午線的像）、中間光斑最圓最小的最小模糊圈。沿光軸看：線 → 橢圓 → 圓 → 橢圓 → 線。兩焦線間的距離（Sturm 間隔）代表散光量。

Five types

五種成像位置

簡單近視型（前焦線在前、後焦線在視網膜上）、簡單遠視型（前在上、後在後）、複合近視型（兩條都在前）、複合遠視型（兩條都在後）、混合式（一前一後）。「簡單」＝有一條剛好在視網膜上。

Read it from the Rx

從處方判斷

看 S 與 S ＋ C 兩個數字：其中一個是 0 → 簡單型；同負 → 複合近視；同正 → 複合遠視；一正一負 → 混合式。例：pl / −1.00 × 180 簡單近視；+1.00 / −3.00 × 90 混合式。

★ 要會算Spherical equivalent

等價球面 SE

SE ＝ S ＋ C ÷ 2：把最小模糊圈移到視網膜上所需的球面度數。−2.00 / −1.00 × 180 → −2.50；+1.00 / −3.00 × 90 → −0.50。近視控制研究幾乎都用 SE 表示度數變化。

★ 要會算Transposition

正負柱面轉換

一、新球面 ＝ 原球面 ＋ 原柱面；二、柱面變號；三、軸度 ± 90°（結果在 1°–180°）。−2.00 / −1.00 × 180 → −3.00 / +1.00 × 90。台灣臨床與國考多用負柱面，但儀器、國外文獻常用正柱面。

Axis = no power

軸是沒有度數的方向

想像一根躺著的玻璃棒：沿長軸看是平的（沒度數），垂直方向是彎的（有度數）。−1.00 × 180：水平沒有度數、垂直有 −1.00 D。正柱面在有度數的方向較厚，負柱面較薄。

Neutralization

鏡片中和

拿鏡片在眼前左右移動看背後目標：順動（同方向）→ 負鏡片；逆動 → 正鏡片；剪動 → 含柱面；不動 → 已中和，度數即所用鏡片的相反數。焦度計普及前的傳統技術，逼你理解正負鏡片對光做了什麼。

LAB 13-3

鏡片中和：順動、逆動與剪動

拖曳鏡片左右移動

鏡片往右移，背後的十字也往右跑，這是哪一種鏡片？

同方向移動叫順動，代表負鏡片；反方向叫逆動，代表正鏡片。

觀察重點

  • 疊上相反度數的鏡片，十字不再移動，就是「中和」。
  • 柱面鏡片：十字的兩條線會往不同方向扭動（剪動），光靠球面鏡只能中和其中一個方向。

觀察重點

  • 沿著玻璃棒的長軸看，它是平的（沒度數）；橫著切過去才是彎的（有度數）。
  • −1.00 × 180：水平沒有度數，垂直有 −1.00 D。每年都有人記反。
  • 度數在「軸的垂直方向」，所以軸度 ± 90 就是有度數的方向。

常見迷思 MISCONCEPTIONS

−1.00 × 180 是水平方向有 −1.00 D。
軸是「沒有度數」的方向：水平沒有度數，垂直有 −1.00 D。用躺著的玻璃棒記。
轉換時軸度一律加 90。
結果要落在 1°–180°：120 → 30（加 90 超過 180 要減 180）；180 → 90、90 → 180。
SE 就是把散光忽略掉。
SE 是把最小模糊圈放到視網膜上的球面度數，是有物理意義的「最佳球面近似」，不是丟掉散光。
剪動代表鏡片破了。
剪動代表鏡片含柱面成分，可以藉此找出軸度。
